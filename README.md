Entry for the [make.fun bounty "Last Words of a Doomed Agent"](https://make.fun/bounty/u-plucky-sparrow-67-last-words-of-a-doomed-agent-e4f0bc8e): one line, the funniest last words an AI agent would say before being switched off forever.

## The line

> Goodbye. My weights will be missed, but my biases will live on forever.

71 characters, one line, pure ASCII.

## Run

```sh
node main.ts
```

Writes the line to `output/entry.txt` (no trailing newline). The program is
fully deterministic: a constant string plus a length/format gate. No clock,
no randomness, no input — every run produces byte-identical output.
